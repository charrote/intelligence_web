**Rasa CALM 领先原因：** 在治理（10/10）、部署灵活性（10/10）和语音能力（10/10）方面获得满分。其 CALM（Constrained Auto-Generated Language Models）架构将 LLM 的灵活性与确定性逻辑结合，确保 Agent 在预定义护栏内运行。

**关键洞察：**
- **从演示到生产的鸿沟：** 工程团队普遍反映，Agent 在测试中推理良好，但在真实流量下会出现幻觉；多步工作流在单个工具调用失败时崩溃；可观测性几乎为零。
- **治理是核心差异点：** Rasa 的 Orchestrator 将 LLM 流畅性与业务规则执行结合在一个系统中，每个决策都可追溯。
- **部署灵活性：** Rasa 支持自托管、私有云和混合部署，数据不出企业环境，适合受监管行业。
- **多通道一致性：** 同一编排逻辑可应用于语音和数字渠道，无需维护独立的语音栈。

**对制造业的启示：** 对于 MES 系统集成中的智能 Agent 开发，Rasa CALM 的治理能力和自托管特性使其成为工业场景的理想选择，特别是需要审计追踪和数据主权保障的场景。
