### Step 3：新建/编辑规则弹窗

点击"新建规则"或"编辑"按钮时弹出模态窗口，表单字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| 规则名称 | text | 必填，`intel_extraction_rule.name` |
| 域 | select | 研究域 / 销售域 |
| 描述 | text | 可选 |
| 抽取范围 | select | 全文 / 仅摘要 / 全文+表格 |
| 状态 | switch | 启用 / 禁用 |
| 字段列表 | dynamic | 见下 |

**字段列表（动态表格）：**

| # | 字段中文名 | 字段标识 | 字段类型 | 必填 | 排序 | 操作 |
|---|-----------|---------|---------|:---:|:---:|------|
| 1 | 厂商名称 | company_name | company | ✓ | 1 | 删除 |
| 2 | 市场份额 | market_share | pct | ✗ | 2 | 删除 |

底部按钮：[➕ 添加字段] [保存规则] [取消]

**字段类型下拉选项：**

## 验收标准

| # | 验收项 | 验证方式 |
|---|--------|----------|
| 1 | 页面可打开，无 JS 报错 | 浏览器 DevTools 控制台无错误 |
| 2 | 规则列表正确显示 | 包含所有规则及其状态 |
| 3 | 新建规则弹窗可打开并保存 | 创建后列表中可见新规则 |
| 4 | 编辑规则弹窗正确填充现有数据 | 验证字段列表正确加载 |
| 5 | 字段列表可动态添加/删除 | 添加/删除后保存正确 |
| 6 | 删除内置规则被阻止 | DELETE 请求返回 403，前端提示"内置规则不可删除" |
| 7 | 立即抽取触发成功 | POST 请求后统计区域更新 |
| 8 | 筛选器（域/状态）正常工作 | 切换筛选后列表正确过滤 |

## 注意事项

1. **字段标识自动生成：** 用户输入"市场份额"时，自动生成 `market_share` 作为 field_key（中文转英文短名逻辑可在前端实现简单规则，如拼音首字母）
2. **内置规则保护：** 删除/修改按钮对 `built_in=1` 的规则需要特殊处理（禁用删除按钮，修改时不显示"删除"操作）
3. **字段类型说明：** 每个字段类型在表单中提供 tooltip 或帮助文本
