## 实施步骤

### Step 1：修改 `tabs.js`

在 `tabs.js` 中找到路由映射表（约第 10 行），新增两个路由：

```javascript
{
  routes: {
    'dashboard': { page: 'dashboard.html', label: '仪表盘' },
    'projects': { page: 'projects.html', label: '项目管理' },
    // ... 现有路由 ...
    'analyst': { page: 'analyst.html', label: 'AI 分析师' },
    'intel-extract': { page: 'intel-extract.html', label: '抽取规则' },  // 新增
    'reports': { page: 'reports.html', label: '报告模板' },              // 新增
    'report-view': { page: 'report-view.html', label: '查看报告' },     // 新增（如果已有 report-view 则跳过）
    'settings': { page: 'settings.html', label: '系统设置' },
  }
}
```

---

### Step 2：修改 `shell.html` 侧栏

在 `shell.html` 的侧栏菜单（约第 60 行区域）中，找到 AI 分析师条目之后，新增两个条目：

```html
<div class="sidebar-item" data-route="analyst" onclick="openTab('analyst')">AI 分析师</div>
<!-- 新增以下两条 -->
<div class="sidebar-item" data-route="intel-extract" onclick="openTab('intel-extract')">抽取规则</div>
<div class="sidebar-item" data-route="reports" onclick="openTab('reports')">报告模板</div>
```
