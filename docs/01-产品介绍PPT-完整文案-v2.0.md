#### 场景一：制造情报 — 「看见趋势」

覆盖维度：🔧 产品与技术 · 🏭 公司与市场 · 📋 政策与标准

面向销售与商务团队

- ✅ 已验证：制造情报 · 销售情报

## Slide 9 · 合作方案

### 【页面文案要点】

**标题：** 快速启动，灵活定制

#### 部署方式

| 方式 | 说明 | 适用场景 |
|------|------|----------|
| **本地部署** | 客户自有服务器运行，一条命令 `docker compose up -d` 启动 | 数据安全敏感、内网环境 |
| **云端部署** | 支持阿里云、腾讯云、AWS、Azure 等主流云平台 | 需要弹性扩展、异地灾备 |
| **混合部署** | 核心数据本地留存，搜索与分析能力云端扩展 | 平衡安全与扩展需求 |

#### 实施周期

| 阶段 | 周期 | 交付内容 |
|------|------|----------|
| 环境部署与系统上线 | **1-3 个工作日** | 完整运行环境、基础数据配置 |
| 业务域定制（首个域） | **3-7 个工作日** | 定制规格文件、数据源配置、前端适配 |
| 数据迁移与历史导入 | 根据数据量评估 | 历史数据批量导入、去重与结构化 |
| AI Agent 接入与调优 | 持续迭代 | MCP Server 对接、分析策略优化 |
| 新域扩展 | **每域 3-5 个工作日** | 新增业务域的规格配置与上线 |

#### 交付清单

- ✅ Docker Compose 部署包（含全部服务容器）
- ✅ 前端 Portal（15 个功能页面，Vanilla HTML/CSS/JS）
- ✅ 共享核心引擎（core/ 目录）
- ✅ 管理员初始账号与部署运维手册
- ✅ API 接口文档、MCP Server 集成指南
- ✅ 技术支持 / 培训服务 / 版本更新 / 定制开发（按需）

## 附录：配色与字体规范速查

### 配色方案

| 用途 | 色值 | 应用场景 |
|------|------|----------|
| **主色调** | `#1a73e8` (科技蓝) | 标题、重点文字、链接 |
| **辅助色** | `#00c853` (增长绿) | ROI 数据、效率提升、CTA |
| **警示色** | `#ff6d00` (紧迫橙) | 痛点、传统方案对比 |
| **背景** | `#0d1117` (深空黑) | 封面和封底背景 |
| **卡片背景** | `#161b22` (深灰) | 内容区域卡片背景 |
| **正文文字** | `#e6edf3` (近白) | 普通正文文字 |
| **次要文字** | `#7a8ba8` (灰蓝) | 注释、辅助说明 |

### 字体规范

| 用途 | 推荐字体 | 字号参考 |
|------|----------|----------|
| **大标题（封面）** | 思源黑体 Bold | 36-68pt |
| **页面标题** | 思源黑体 Bold | 24-28pt |
| **正文** | 思源黑体 Regular | 12-14pt |
| **数据/数字** | DIN Alternate Bold | 32-42pt（关键数字） |
| **辅助说明** | 思源黑体 Regular | 10-12pt |

### 设计原则

1. **每页只传递一个核心信息** — 不要让听众一次消化太多内容
2. **数字要大** — ROI 页的数字建议用页面 1/3 的高度展示
3. **对比要鲜明** — 传统方案用灰色，Intelligence Web 用亮色
4. **留白要充足** — 每页内容不超过 6 行 bullet points
5. **流程图简洁** — 架构图不超过 5 个元素，用颜色区分层级
6. **封面封底呼应** — 保持一致的视觉风格，形成完整体验
