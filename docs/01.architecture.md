# Intelligence Web 系统架构文档

> 最后更新：2026-07-23 ｜ 版本：v1.0

---

## 1. 系统概述

Intelligence Web 是一个面向领域情报采集管理平台，为行业提供类似竞争对手追踪、市场洞察和客户挖掘能力。系统采用模块化设计，共享底层核心引擎，目前支持搭建制造情报和销售情报两个独立域。

**核心价值主张**：一站式情报收集 → 结构化存储 → AI 辅助分析 → 行动闭环。

---

## 2. 技术栈总览

| 层级 | 技术选型 | 用途 |
|------|----------|------|
| **前端** | Vanilla HTML + CSS + JS | 门户 SPA（无框架依赖） |
| **网关** | Nginx Alpine | 反向代理 + 认证请求中间件 |
| **后端** | Python Flask | RESTful API（两域共用同一套核心） |
| **搜索** | Meilisearch v1.12 | 全文检索引擎 |
| **数据存储** | SQLite | 持久化存储（单文件，零运维） |
| **容器编排** | Docker Compose | 服务编排与生命周期管理 |
| **AI 接入** | MCP Server (stdio) | JSON-RPC over stdio，对接 Claude/Hermes/OpenClaw 等 Agent |

## 5. 核心模块拆解

### core/app.py —— Flask App Factory

中央路由注册中心。所有 API 端点通过 `create_app(project_root, spec)` 工厂函数内的装饰器动态注册。负责 CORS 策略执行、JWT 认证中间件，并将数据操作委托给域特定的库。核心职责：路由定义、请求/响应格式化、认证门禁。

### core/db.py —— 数据库抽象层

SQLite 封装，提供面向所有域实体的类型化 CRUD 操作。通过上下文管理器实现连接池，保证事务隔离，并提供模式初始化与迁移例程。包含密码哈希工具（SHA-256 + 随机盐值）、用户种子逻辑，以及基于异或混淆的设置持久化层（敏感键值加密存储）。设计上支持水平扩展，从控制器层屏蔽直接 SQL 暴露。

### core/domain.py —— 规格构建器

工厂函数 `build_spec(...)` 构造标准化的域配置字典，同时被 Flask App Factory 和 MCP Server Handler 消费。封装所有可调参数：slug 标识符、端口分配、状态枚举、目标类型层级、分类 TTL 策略、搜索引擎配置、默认实体种子。作为跨服务域身份的唯一真相源，通过集中定义模式防止配置漂移，消除跨多文件分散声明常量带来的重复风险。

### core/datasource.py —— 数据源生命周期管理器

实现外部数据采集中端点的全量 CRUD 操作，各域数据库实例独立跟踪。通过关联表（`project_datasources`）维护关系完整性，支持项目与监控源之间的灵活多对多关联，无需反规范化代价。通过 `update_source_last_crawled()` 时间戳追踪机制提供增量爬取能力，支持差异同步算法以优化周期性轮询上游 API 或网站时的带宽利用率。

### core/project.py —— 项目控制器

管理智能采集项目，支持可配置频率（每日/每周/每月）、作用域定义、AI 侦察兵自定义指令、动态数据源分配。支持在不删除的情况下切换项目激活状态。

### core/target_types.py —— 实体分类注册表

定义情报条目的分类体系（产品、技术、竞争对手、市场、客户、供应商、投资）。每种类型携带元数据属性：UI 渲染用颜色代码、视觉区分的图标、跨视图保持一致展示的排序顺序。

## 6. 域规格对比

两个域共享完全一致的架构模式，但在业务语义上有所不同。

### 研究域（intelligence_web，端口 8766）
- 用途：追踪制造技术趋势、竞争格局变化、监管发展
- target_types：产品、技术、公司、市场、政策、标准
- 状态流：待处理 → 处理中 → 已完成
- 特色功能：Meilisearch 驱动的全文搜索集成
- 主题色：紫色 (#722ed1)
- 分配 Agent：贾维斯、美雪、南希、马格南

### 销售域（intelligence_sales，端口 8767）
- 用途：竞争情报、客户挖掘、交易管道管理
- target_types：竞争对手、市场、客户、供应商、投资、产品
- 状态流：待处理 → 合格商机 → 方案报价 → 商务谈判 → 成交/丢标
- 特色功能：交易价值追踪、公司归属、行业分类
- 主题色：蓝色 (#1890ff)
- 分配 Agent：贾维斯、南希

## 8. MCP Server 集成

MCP Server（mcp_server/）通过 JSON-RPC over stdio 传输协议，将情报平台能力暴露给外部 AI Agent：
- 搜索、创建、更新情报条目的工具定义
- 跨研究域和销售域数据库的跨域查询
- 实体解析与关联能力
- 实时数据源监控与告警

## 9. 部署架构

```
Docker Compose 服务:
  research    -> Flask API（端口 8766）
  sales       -> Flask API（端口 8767）
  nginx       -> 反向代理（端口 8765）
  meilisearch -> 搜索引擎（端口 7700）
```

所有服务通过 volume 挂载共享同一份 core/ 目录，确保各域实例代码一致。数据库文件（SQLite）存储在域特定的 data/ 子目录中，实现数据隔离。

## 10. 关键设计原则

1. **共享核心，分离域**：核心逻辑与域无关；每个域提供自己的配置和入口点。
2. **配置即代码**：域身份、路由、行为在 spec 文件中定义，而非硬编码。
3. **最小依赖**：SQLite 消除外部数据库依赖；Meilisearch 是唯一的对外服务。
4. **AI 优先**：MCP Server 集成使 AI Agent 与平台数据的交互无缝化。
5. **容器就绪**：所有服务 Docker 化，通过 Docker Compose 编排，简化的部署和扩展。
