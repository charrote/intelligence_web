## 验证方法

### 自动验证脚本（建议）

在项目目录下新建 `scripts/test_analyst.py`：

```python
"""
AI 分析师重构功能验收验证脚本。
用法: python scripts/test_analyst.py
"""
import json, requests, sys

BASE = "http://localhost:8766"
HEADERS = {"Authorization": "Bearer <test_token>"}

passed = 0
failed = 0

def check(desc, condition, detail=""):
    global passed, failed
    if condition:
        print(f"  ✅ {desc}")
        passed += 1
    else:
        print(f"  ❌ {desc} — {detail}")
        failed += 1

# 1. 数据层
print("\n=== 数据层 ===")
r = requests.get(f"{BASE}/api/extract/rules", headers=HEADERS)
rules = r.json()
check("内置规则 ≥2", len(rules) >= 2, f"got {len(rules)}")

r = requests.get(f"{BASE}/api/reports/templates", headers=HEADERS)
templates = r.json()
check("内置模板 ≥4", len(templates) >= 4, f"got {len(templates)}")

r = requests.get(f"{BASE}/api/reports/scheduler", headers=HEADERS)
sched = r.json()
check("调度器状态正常", sched.get("scheduler_enabled") == 1)

# 2. 抽取功能
print("\n=== 抽取功能 ===")
r = requests.get(f"{BASE}/api/extract/stats", headers=HEADERS)
stats = r.json()
check("抽取覆盖率 >0", stats.get("coverage_pct", 0) > 0, f"got {stats.get('coverage_pct')}%")

# 3. 报告功能
print("\n=== 报告功能 ===")
r = requests.get(f"{BASE}/api/reports/overview", headers=HEADERS)
overview = r.json()
check("有报告执行记录", len(overview) > 0)

# 汇总
print(f"\n=== 汇总: {passed} passed, {failed} failed ===")
sys.exit(0 if failed == 0 else 1)
```

### 手动验证

对自动脚本无法覆盖的项目（前端渲染、图表显示等），逐项人工验证。
