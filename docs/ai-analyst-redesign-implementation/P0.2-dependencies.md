# P0.2 — 依赖安装

> **状态：** ⏳ 待开始
> **前置条件：** 无（Phase 0 基础任务）
> **依赖本任务的后续任务：** P0.3

---

## 目标

在项目的 Python 依赖配置文件中新增 APScheduler 和 Jinja2 依赖。

---

## 实施步骤

### Step 1：修改 requirements.txt

找到 `intelligence_web/requirements.txt`（或项目根目录的 requirements.txt，视 Dockerfile 实际引用路径而定），新增：

```
apscheduler>=3.10,<4.0
jinja2>=3.1,<4.0
```

### Step 2：修改 Dockerfile

找到 `intelligence_web/Dockerfile.api`，在 `RUN pip install` 行中确认新依赖被包含，或确保 `requirements.txt` 被正确引用。

当前 Dockerfile（`intelligence_web/Dockerfile.api`）已有：
```dockerfile
RUN pip install flask pyjwt requests python-dotenv meilisearch
```

改为：
```dockerfile
COPY requirements.txt .
RUN pip install -r requirements.txt
```

或直接在 RUN 行追加：
```dockerfile
RUN pip install apscheduler jinja2
```
