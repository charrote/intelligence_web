## Slide 9 · 技术架构速览（IT 友好页）

**标题：** 为 IT 负责人准备的架构透明度  

**四服务容器化架构：**

| 服务 | 端口 | 技术栈 | 角色 |
|------|------|--------|------|
| **Research API** | 8766 | Flask + Python 3.11 | 制造情报业务引擎 |
| **Sales API** | 8767 | Gunicorn + Python 3.11 | 销售情报业务引擎 |
| **Gateway** | 8765 | Nginx Alpine | 反向代理 + JWT 鉴权 |
| **Meilisearch** | 7700 | Meilisearch v1.12 | 全文检索引擎 |

**关键架构原则：**
- 🔀 **共享内核** — 所有业务域通过 Docker Volume 挂载同一 `core/` 目录
- 🧩 **分离领域** — 各域数据完全隔离，通过 SQLite 独立文件实现
- 🔌 **MCP Server** — 18 个工具方法，AI Agent 通过标准化协议直接访问数据
- 🚀 **零外部数据库依赖** — 除 Meilisearch 外无需任何额外服务

**视觉建议：** 架构图简化版（客户端→网关→业务域→核心引擎→数据层），用不同颜色区分层级  
**演讲者备注：** IT 负责人关心的三个问题：能不能部署？能不能维护？能不能扩展？ — 这页全部回答。

## Slide 11 · AI 协作模式：人与机的高效飞轮

**标题：** 不是工具，是协作伙伴  

**五步飞轮模型：**

```
① AI Agent 每日自动巡检指定数据源
      ↓
② AI 对采集内容进行初步分析和归类
      ↓
③ AI 在每条情报下留下观察和建议
      ↓
④ 人类员工做出最终判断和行动决策
      ↓
⑤ 人类反馈反哺 AI，持续提升分析精度
```

**关键差异化：**
- 这不是一个"录入工具"，是让人类和 AI Agent **共同工作** 的平台
- 每一次人工反馈都在训练 AI，形成**正向飞轮**
- 18 个 MCP 工具方法，支持 Claude / Hermes / OpenClaw 等多 Agent 接入

**视觉建议：** 循环飞轮图，五个步骤形成一个闭环，中心标注"正向飞轮效应"  
**演讲者备注：** 这是产品的灵魂 — "AI 不是替代人，是让每个人变得更强大"。

## Slide 12 · 安全与合规

**标题：** 企业级安全，从第一天就内置  

| 安全维度 | 实现方式 |
|----------|----------|
| **认证** | JWT Bearer Token（HS256），密码 SHA-256 + 随机盐存储 |
| **密钥保护** | API Key / Agent Key 落地 XOR 混淆，API 响应中脱敏为 `***` |
| **CORS** | 环境变量严格白名单控制允许来源域名 |
| **RBAC 权限** | Admin / Manager / Analyst / Viewer 四级角色，精细到菜单级操作授权 |
| **审计日志** | 所有变更操作记录操作人身份和时间戳，满足合规追溯需求 |

**一句话总结：** 每一个操作都被记录，每一个密钥都被保护，每一次访问都有据可查。

**视觉建议：** 盾牌图标 + 五个安全维度的小图标环绕，用绿色系传递安全感  
**演讲者备注：** 对老板和 IT 负责人都重要 — "这不是一个 demo 项目，这是能上生产环境的系统"。

| `## Slide N · 标题` | 每个 `##` 对应一页 PPT，共 18 页 |
| **主标题 / 副标题** | PPT 页面标题和副标题 |
| 表格 | PPT 中的数据对比表、功能表 |
| 要点列表 | PPT 中的 bullet points |
| **视觉建议** | 给 PPT 设计师 / Agent 的布局与配色参考 |
| **演讲者备注** | 演讲者的口头表达参考，PPT 中不显示 |

### 配色方案建议

| 用途 | 色值 | 说明 |
|------|------|------|
| 主色调 | `#1a73e8` (科技蓝) | 标题、重点文字 |
| 辅助色 | `#00c853` (增长绿) | ROI 数据、效率提升 |
| 警示色 | `#ff6d00` (紧迫橙) | 痛点、对比表中的传统方案 |
| 背景 | `#0d1117` (深空黑) | 封面和封底背景 |
| 卡片背景 | `#161b22` (深灰) | 内容区域卡片背景 |
| 文字 | `#e6edf3` (近白) | 正文文字 |

### 字体建议

| 用途 | 推荐字体 |
|------|----------|
| 标题 | Noto Sans SC Bold / 思源黑体 Bold |
| 正文 | Noto Sans SC Regular / 思源黑体 Regular |
| 数据/数字 | DIN Alternate Bold / Montserrat Bold（数字用无衬线粗体更有冲击力） |

### 关键设计原则

1. **每页只传递一个核心信息** — 不要让听众一次消化太多内容
2. **数字要大** — ROI 页的数字建议用页面 1/3 的高度展示
3. **对比要鲜明** — 传统方案用灰色，Intelligence Web 用亮色
4. **留白要充足** — 每页内容不超过 6 行 bullet points
5. **流程图简洁** — 架构图不超过 5 个元素，用颜色区分层级
